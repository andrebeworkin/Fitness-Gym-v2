# Next Features (Post-Demo)

Priority-ordered follow-up phase after polish and demo readiness.

## 1) Entitlement policy engine

- Configurable late-cancel and no-show policy by membership type.
- Rule versioning and effective-date policy changes.
- Automated monthly award and expiry jobs.
- Manager override actions with audit trail.

## 2) Reporting exports and trend views

- CSV exports for roster health, attendance, and payments.
- Trend snapshots (weekly/monthly) for adherence and utilization.
- Saved report presets by location/operator.

## 3) Scheduling quality-of-life

- Direct client reschedule into open slot with conflict-safe server mutation.
- Calendar/grid UI for manager schedule (still server-validated).
- Waitlist and auto-fill candidate suggestions.

## 4) Program operations

- Manager-reviewed one-click apply for approved `program_change_requests`.
- Program line version diff and rollback tools.
- Bulk assignment for cohorts/challenges.

## 5) Comms and reminders

- Appointment reminders and follow-up nudges.
- Internal task/note assignment workflows.
- Client-facing progress milestone nudges.

## 6) Finance maturity

- Deeper invoice/payment reconciliation workflows.
- Revenue and aging trend reports.
- Document export/attachment lifecycle polish.
